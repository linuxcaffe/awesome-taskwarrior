Run pre-pipeline checks for the current project before handing off to the pipeline.

## Project state

!`echo "--- Project ---" && basename $(pwd)`
!`echo "--- Git status ---" && git status --short 2>/dev/null || echo "(not a git repo)"`
!`echo "--- Versions ---" && grep "^version=" *.meta 2>/dev/null; grep "^VERSION=" *.install 2>/dev/null; grep "^VERSION\s*=" *.py 2>/dev/null`
!`echo "--- Installer type ---" && head -5 *.install 2>/dev/null | grep -i "handcrafted" && echo "HANDCRAFTED" || echo "Generated"`
!`echo "--- .orig files ---" && ls *.orig 2>/dev/null || echo "(none)"`
!`echo "--- Debug/timing markers ---" && grep -l "Auto-generated by make-awesome" *.py 2>/dev/null | head -5 || echo "(none)"`

## Checklist

Evaluate each item and mark ✓ or ✗:

- [ ] **Versions match** across `.meta`, `.install` (if HANDCRAFTED), and `.py`
- [ ] **No unexpected git changes** — unstaged/staged files are intentional
- [ ] **No leftover .orig files** — these are debug/timing backups, not for committing
- [ ] **HANDCRAFTED installer** VERSION bumped manually (if applicable)
- [ ] **Debug infrastructure present** if this app has been through `--debug`
  (check for `TW_DEBUG` in .py files — confirm it's the fixed version using
  `~/.task/logs/debug/` not cwd-based path)

**Final verdict:**
- All pass → "✓ Ready for pipeline push — run: `make-awesome.py --meta --install --push "message"`"
- Any fail → list what needs fixing, in priority order
